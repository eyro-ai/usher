Superseded · 2026-08-12

This map described a design that no longer exists

It documented four zones, permission classes discovered from Drive ACLs, an edge table with provenance, per-class caches, promotion and demotion flows, and drift detection.

All of that was removed by D12. The system is now one Drive folder, three sources, and a two-tab index. The exhaustive component map existed because the design had grown far past its stated purpose — a searchable memory of recordings.

Most of the complexity chained off a single premise: a pocket recorder has no permission model to inherit. Seven decisions followed from it, none of which were needed, because the requirement that justified them was never confirmed.

What survived the cut, because each is cheap and prevents a failure invisible from the reader's side:

  • Evidence must appear verbatim in the source, or the claim is dropped
  • Exclusion logs record a rule and a count, never what was excluded
  • Mutable records are refetched live, never read from the sheet
  • Names resolve to ids before filtering, never after

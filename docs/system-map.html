The single most important edge in this diagram

Where an edge is allowed to live

Never

What never happens

Boundaries are easier to hold when they are written down as prohibitions rather than inferred from the happy path.

  • No status is ever stored. Linear state and open-PR state are refetched on every answer, or the answer says the source was unreachable.
  • No raw content is written outside its target class. Never written somewhere convenient and moved afterwards.
  • No skip log names what it skipped. Rule id and count only.
  • No suppressed-result counts. Out-of-scope material is absent, never "3 hidden".
  • No cross-class synthesis is persisted downward. Answering across classes you hold is fine; writing that answer into the broader one is not.
  • No claim without verbatim evidence. Failures are discarded, never repaired.
  • No inferred edge presented as fact, and no silent traversal of one.
  • No writes back to Plaud, Linear, or GitHub. The KB is read-only toward its sources.
  • No service token holding everyone's access. The agent acts with the asking person's credentials.
  • No counts presented as measurements. The corpus is a convenience sample that merely looks tabular.

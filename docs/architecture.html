Shape

A router, five sources, one moving part

Routing

The only real intelligence

Knowing where an answer lives is the thing worth building. Everything else is already solved by the sources themselves.

"What do we know about X?"all five, merged
  • Fan out when unscoped. The cost is latency; the alternative is silently missing where the answer was.
  • Refetch, never remember. No cache anywhere, so nothing can go stale.
  • Say what was searched — an incomplete answer should look incomplete.
  • Empty is an answer. "Nothing in Linear or Drive" beats plausible reconstruction.
Ingest

Inbox as a queue

Plaud pushes transcripts and summaries into PlaudInbox/ via Zapier — already transcribed, already summarized, so the routine never re-does either. It excludes, categorizes from a closed list, files under Meetings/<category>/, and moves the original to Processed/.

Done means moved. That is the entire idempotency mechanism, and a human can verify it by looking at the folder. Errors go to Failed/ rather than retrying forever or disappearing.

Two things that quietly matter

Categories come from a closed list in config. An open-ended one invents two hundred near-synonyms within a month. It is a schema — treat it as one.

The skip log records a rule and a count, never the content. A descriptive log recreates excluded material in a second place, which is exactly what the exclusion existed to prevent — and a helpful log is the obvious thing to write.

Access

Identity does the work

Everything runs under the user's own account, so each agent sees exactly what that person sees. No tiers, no permission model, and no derived index that could leak — the earlier design spent seven decisions on this problem, and running as the user dissolves it.

Twenty is the one exception: its key is workspace-wide rather than tied to a person, so the assumption holds for four sources out of five. For a small team that is probably fine — it is recorded so it stays a known gap rather than a surprise.

Risk

What to watch

  • Fan-out latency. Five sources per unscoped question. The fix is better routing, never a cache.
  • Plaud's summary quality is load-bearing, since nothing re-summarizes. If those summaries prove thin, add a distillation step — and only then does verbatim-evidence checking become relevant again.
  • Twenty's workspace-scoped key, above.
  • Category drift if the closed list is edited casually.
Deliberately not built

No index — five good search engines beat a sixth that unifies them, and one is built only when a real question fails to find a real answer. No command execution from recordings: voice has no send button, so every utterance near the device would be a candidate instruction.
